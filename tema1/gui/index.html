3. Crea una estructura de directorios

Utilizando el gestor de archivos, crea exactamente esta estructura dentro de tu carpeta personal:

├── DOCUMENTOS
│   └── PERSONAL

De momento puedes crear todas las carpetas con la GUI. Más adelante volveremos a crear una carpeta desde el Terminal.

🔒 No se permite copiar y pegar.
La captura formará parte del archivo final que entregarás.
¿Para qué sirve organizar en carpetas? Imagina que descargas muchos trabajos, fotos y documentos. Si los dejas todos juntos será difícil encontrarlos. Una estructura de carpetas permite clasificarlos por asignatura, proyecto, fecha o tipo de contenido.
🏠 EN WINDOWS. Harías lo mismo desde el Explorador de archivos: crear carpetas y subcarpetas y organizarlas jerárquicamente.
Reto 4 · 4 puntos

4. Crea, guarda, mueve y renombra un archivo

Ahora utilizarás el editor de texto de EducaAndOS.

  1. Abre el editor de texto.
  2. Crea un archivo nuevo.
  3. Escribe dentro tu nombre y apellidos.
  4. Guárdalo como datos.txt dentro de Practica_SO/DOCUMENTOS.
  5. Ciérralo y vuelve a abrirlo para comprobar que se ha guardado correctamente.
  6. Mueve el archivo a Practica_SO/DOCUMENTOS/PERSONAL.
  7. Finalmente, cámbiale el nombre a identidad.txt.
Ejemplo real. Descargas un archivo llamado documento1.pdf. Puedes moverlo a Facturas/2026 y renombrarlo como Factura_luz_septiembre.pdf. El contenido no cambia, pero después será mucho más fácil localizarlo.
🔒 No se permite copiar y pegar.
Haz clic aquí y pulsa Ctrl+V.
🏠 EN WINDOWS. Puedes hacer lo mismo con el Bloc de notas y el Explorador de archivos: guardar, mover y cambiar el nombre de un archivo.
